# AI Dataset Linter & Sanitizer CLI

Lightweight CLI tool for validating and linting JSON datasets prior to fine-tuning or training Machine Learning models.

## Features
- Row and column counting
- Missing / null value detection
- Duplicate record identification
- Structured reporting with Pydantic v2 validation

## Quick Start

1. Clone the repository:
```bash
git clone https://github.com/GreebBrothet/dataset-cleaner-cli.git
cd dataset-cleaner-cli
pip install -r requirements.txt
python main.py
```
